# Dev Assist Kit

Kit liviano para acelerar trabajo futuro en `lg-terracon` sin tocar codigo de negocio.

## Que incluye

- [Flujos comunes](./flujos-comunes.md)
- [Checklist de calidad antes de merge](./checklist-calidad.md)
- [Snippets y comandos utiles](./snippets-comandos.md)

## Como usarlo

1. Abre el archivo del flujo que calza con la tarea.
2. Sigue el checklist antes de pedir review o merge.
3. Copia los comandos/snippets que te ahorren tiempo en este repo.

## Alcance

- Solo documentacion bajo `dev-assist/**`.
- No modifica LG/PWA ni logica de negocio.
- Prioriza comandos que ya existen en `package.json` y `scripts/`.
